# Marouane El Aasri

Software developer. I build tools in Python around security and AI-agent safety — things that sit in front of models or agents and decide what they are allowed to do with real data and real tools.

## Featured projects

### [AgentTaint](https://github.com/Marouane2005/AgentTaint)

Tracks where data came from in AI agent workflows and allows, blocks or asks for confirmation before sensitive MCP tool calls run.

[Try the live demo](https://agenttaint-demo.onrender.com/demo/) — it is on a free server, so the first load can take a little while.

[![AgentTaint security overview](https://raw.githubusercontent.com/Marouane2005/AgentTaint/main/docs/screenshots/01-overview.png)](https://github.com/Marouane2005/AgentTaint)

### [AegisLLM](https://github.com/Marouane2005/aegisllm)

A self-hosted gateway in front of OpenAI-compatible chat APIs. It can mask personal data, block a set of prompt-injection patterns, and write an audit row for every call.

### [Qalam](https://github.com/Marouane2005/qalam)

Document intelligence for Arabic, French and English. It reads PDFs, scans and Word files, then you can summarize, translate, extract fields, or ask questions that cite a page.

### [InvoiceGuard](https://github.com/Marouane2005/InvoiceGuard)

A self-hosted service that reads invoices, checks the numbers, and puts anything doubtful in a short list for a person to confirm.

### [Sentinel-AI](https://github.com/Marouane2005/sentinel-ai-cybersecurity)

A deep-learning network intrusion detection system with SHAP explanations, trained on UNSW-NB15. [Live demo](https://huggingface.co/spaces/xomarouane/sentinel-ai-cybersecurity).

**Also:** [Security Audit Framework](https://github.com/Marouane2005/Security-Audit-Framework) (automated Windows security auditing and HTML reporting), [Password Checker](https://github.com/Marouane2005/password-checker) (a small CLI that scores password strength), and [Diabetes Risk AI](https://github.com/Marouane2005/diabetes-risk-ai) (a Streamlit app that estimates diabetes risk from a few clinical measurements — for learning only, not a medical device).
